이 글은 블로그가 지원하는 문법을 모두 보여 줍니다.

## 글자 강조

문장 안에서 **굵게**, *기울임*, ***굵은 기울임***, `인라인 코드`를 쓸 수 있습니다. [링크](https://developer.mozilla.org/ko/)도 넣을 수 있습니다.

### 인용문

> 좋은 글은 읽는 사람의 시간을 아낍니다.
>
> > 인용문 안에 인용문을 넣을 수도 있습니다.

## 목록

- 첫 번째 항목
- 두 번째 항목
  - 중첩된 항목
    - 더 깊은 항목
- 세 번째 항목

1. 글을 쓴다
2. 빌드한다
   1. 파서가 HTML로 바꾼다
   2. 템플릿에 넣는다
3. 배포한다

## 코드 블록

```js
function greet(name) {
  const message = `안녕하세요, ${name}님! 이 줄은 코드 블록이 페이지가 아니라 블록 안에서만 가로로 스크롤되는지 확인하기 위해 일부러 길게 작성했습니다.`;
  return message;
}
```

## 표

| 문법 | 표기 | 정렬 |
| :--- | :---: | ---: |
| 굵게 | `**글자**` | 왼쪽 |
| 기울임 | `*글자*` | 가운데 |
| 인라인 코드 | `` `글자` `` | 오른쪽 |
